# CasinoRoyale

API REST en Spring Boot de un juego de dados tipo casino.

## Base de datos (usuario y contraseña)
Por defecto usa:
- **Usuario:** `root`
- **Contraseña:** (vacía)

Si tu MySQL tiene otro usuario o contraseña, defínelos como variables de entorno antes de ejecutar:
- `DB_USER=tu_usuario`
- `DB_PASSWORD=tu_contraseña`
